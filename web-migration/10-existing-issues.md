# 10: Existing issues found during the analysis

These are bugs, risks and stale artifacts in the current code (commit `278fddca`) that came up while
analyzing it for the migration. Most of them matter even without the web frontend. The **Plan**
column says where the migration handles them. Paths are relative to `hql-builder/`.

Severity: **high** means data loss, a security problem or a resource leak; **medium** means wrong
behavior; **low** means cleanup.

| # | Severity | Issue | Location | Plan |
